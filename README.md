# Tejas S Shetty — Next.js Portfolio

A modern, responsive portfolio built with Next.js and plain CSS.

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Build for production

```bash
npm run build
npm start
```

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Customize

Edit `app/page.js` to change:
- About section
- Skills
- Projects
- Experience
- Email
- Social links

Edit `app/globals.css` to change colors, spacing, typography and layout.

Replace `tejas@example.com` with your real email before publishing.
